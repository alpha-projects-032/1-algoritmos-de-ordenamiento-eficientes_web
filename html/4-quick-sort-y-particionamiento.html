Quick Sort y particionamiento

Comprender cómo Quick Sort utiliza un pivote, el particionamiento y la recursión para organizar los elementos de una colección.

Introducción

Quick Sort es un algoritmo de ordenamiento eficiente basado en la estrategia divide y vencerás.

A diferencia de Merge Sort, no divide necesariamente la lista por la mitad. En su lugar, selecciona un elemento denominado pivote y organiza los demás elementos alrededor de él.

1. Estrategia general de Quick Sort

1. Elegir pivote

Seleccionar un elemento que funcionará como referencia.

2. Particionar

Separar elementos menores, iguales y mayores que el pivote.

3. Ordenar

Aplicar Quick Sort recursivamente a las particiones.

Elegir pivote → Particionar → Ordenar

2. ¿Qué es el pivote?

El pivote es un elemento seleccionado de la lista que sirve como referencia para distribuir los demás valores.

[8, 3, 6, 2, 7]

3. Proceso de particionamiento

Consideremos:

[9, 4, 7, 3, 8, 2]

Si utilizamos 7 como pivote:

9 > 7 → mayores
4 < 7 → menores
7 = 7 → iguales
3 < 7 → menores
8 > 7 → mayores
2 < 7 → menores

4. Aplicar Quick Sort nuevamente

Las particiones menores y mayores también deben ordenarse.

quick_sort([4, 3, 2])

↓

[2] + [3] + [4]

↓

[2, 3, 4]

↓

[] + [8] + [9]

Resultado final: [2, 3, 4, 7, 8, 9]

5. Caso base

Si una lista contiene uno o ningún elemento, ya se considera ordenada.

if len(lista) <= 1:
    return lista

6. Estrategias para seleccionar el pivote

Primer elemento 
pivote = lista[0]
Último elemento 
pivote = lista[-1]
Elemento central 
pivote = lista[len(lista) // 2]

7. Particiones equilibradas y desequilibradas

Partición equilibrada 
[3, 2, 1] [5] [8, 6, 7]

Favorece un comportamiento cercano a O(n log n).

Partición desequilibrada 
[] [1] [2, 3, 4, 5]

Puede acercar el algoritmo a O(n²).

8. Implementación sencilla en Python

def quick_sort(lista):

    if len(lista) <= 1:
        return lista

    pivote = lista[len(lista) // 2]

    menores = []
    iguales = []
    mayores = []

    for elemento in lista:

        if elemento < pivote:
            menores.append(elemento)

        elif elemento == pivote:
            iguales.append(elemento)

        else:
            mayores.append(elemento)

    return (
        quick_sort(menores)
        + iguales
        + quick_sort(mayores)
    )
numeros = [8, 3, 6, 2, 7, 1, 5, 4]

resultado = quick_sort(numeros)

print(resultado)
Resultado:
[1, 2, 3, 4, 5, 6, 7, 8]

12. Complejidad de Quick Sort

Caso promedio

Cuando las particiones son relativamente equilibradas:

O(n log n)
Peor caso

Cuando las particiones resultan altamente desequilibradas:

O(n²)

Síntesis

Quick Sort organiza los datos seleccionando un pivote y distribuyendo los elementos en grupos menores, iguales y mayores.

Las particiones se procesan recursivamente hasta alcanzar listas suficientemente pequeñas y posteriormente se unen para producir el resultado ordenado.

Su rendimiento promedio es O(n log n), aunque particiones muy desequilibradas pueden provocar un comportamiento cercano a O(n²).
