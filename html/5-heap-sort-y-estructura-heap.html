Heap Sort y estructura Heap

Comprender cómo Heap Sort utiliza una estructura Heap, la operación heapify y el intercambio de elementos para realizar un ordenamiento O(n log n).

Introducción

Heap Sort es un algoritmo de ordenamiento eficiente que utiliza una estructura denominada heap.

Para ordenar de forma ascendente se utiliza normalmente un Max Heap, donde el elemento de mayor valor se mantiene en la raíz y puede colocarse progresivamente en su posición final.

1. ¿Qué es un Heap?

Un heap es una estructura basada en un árbol binario que mantiene una determinada relación entre los nodos padres y sus hijos.

En un Max Heap, cada nodo padre posee un valor mayor o igual que el de sus hijos.

       9
     / \
    7   8
   / \  / \
  3  2 5  4

2. Max Heap y Min Heap

Max Heap

El elemento de mayor valor ocupa la raíz.

Padre >= hijos
Min Heap

El elemento de menor valor ocupa la raíz.

Padre <= hijos

3. Representación del Heap mediante una lista

Aunque visualmente se representa como un árbol, un heap puede almacenarse directamente mediante una lista.

heap = [9, 7, 8, 3, 2, 5, 4]
Lista
[9, 7, 8, 3, 2, 5, 4]
Árbol

    3  2 5  4

4. Relación entre índices

Si un nodo se encuentra en la posición i, sus hijos pueden calcularse directamente.

Hijo izquierdo
2 * i + 1
Hijo derecho
2 * i + 2
heap = [9, 7, 8, 3, 2, 5, 4]

i = 0

izquierda = 2 * 0 + 1 = 1
derecha   = 2 * 0 + 2 = 2

heap[1] = 7
heap[2] = 8

5. Operación heapify

heapify permite corregir una parte del árbol cuando no cumple la propiedad del heap.

Antes 
    4
   / \
  9   7

No cumple: 9 > 4.

Después de heapify 
    9
   / \
  4   7

La propiedad del Max Heap ha sido restaurada.

6. Función heapify() en Python

def heapify(lista, n, i):
    mayor = i

    izquierda = 2 * i + 1
    derecha = 2 * i + 2

    if izquierda < n and lista[izquierda] > lista[mayor]:
        mayor = izquierda

    if derecha < n and lista[derecha] > lista[mayor]:
        mayor = derecha

    if mayor != i:
        lista[i], lista[mayor] = lista[mayor], lista[i]

        heapify(lista, n, mayor)

7. Parámetros de heapify()

lista

Contiene los elementos que representan el heap.

n

Indica cuántos elementos forman parte actualmente del heap.

i

Representa la posición del nodo que se está verificando.

8. Intercambio de elementos

Si uno de los hijos es mayor que el nodo actual, se realiza un intercambio.

if mayor != i:
    lista[i], lista[mayor] = lista[mayor], lista[i]
Antes
[4, 9, 7]
Después
[9, 4, 7]

9. Construcción del Max Heap

Antes de comenzar el ordenamiento, la lista debe reorganizarse como un Max Heap.

n = len(lista)

for i in range(n // 2 - 1, -1, -1):
    heapify(lista, n, i)
Lista inicial:
[4, 10, 3, 5, 1]

Max Heap:
[10, 5, 3, 4, 1]

10. Extracción del elemento mayor

Una vez construido el Max Heap, el valor mayor se encuentra en la raíz.

lista[0], lista[i] = lista[i], lista[0]
Antes:
[10, 5, 3, 4, 1]

Intercambio:
10 ↔ 1

Después:
[1, 5, 3, 4, 10]
El valor 10 ya se encuentra en su posición definitiva.

12. Implementación completa de Heap Sort

def heapify(lista, n, i):
    mayor = i

    izquierda = 2 * i + 1
    derecha = 2 * i + 2

    if izquierda < n and lista[izquierda] > lista[mayor]:
        mayor = izquierda

    if derecha < n and lista[derecha] > lista[mayor]:
        mayor = derecha

    if mayor != i:
        lista[i], lista[mayor] = lista[mayor], lista[i]

        heapify(lista, n, mayor)


def heap_sort(lista):
    n = len(lista)

    for i in range(n // 2 - 1, -1, -1):
        heapify(lista, n, i)

    for i in range(n - 1, 0, -1):
        lista[0], lista[i] = lista[i], lista[0]

        heapify(lista, i, 0)


numeros = [4, 10, 3, 5, 1]

heap_sort(numeros)

print(numeros)
Resultado
[1, 3, 4, 5, 10]

14. Seguimiento de la ejecución

Podemos agregar mensajes para observar la construcción y reducción del heap.

def heap_sort(lista):
    n = len(lista)

    for i in range(n // 2 - 1, -1, -1):
        heapify(lista, n, i)

    print("Max Heap:", lista)

    for i in range(n - 1, 0, -1):

        lista[0], lista[i] = lista[i], lista[0]

        print("Después del intercambio:", lista)

        heapify(lista, i, 0)

        print("Heap restaurado:", lista)

15. Flujo general de Heap Sort

heap_sort(lista)
↓

↓

↓

↓

↓

↓

16. Complejidad de Heap Sort

Escenario Complejidad
Mejor caso O(n log n)
Caso promedio O(n log n)
Peor caso O(n log n)
Heap Sort mantiene un comportamiento temporal predecible incluso en su peor caso.

17. Uso de memoria

Heap Sort puede reorganizar los elementos directamente dentro de la lista.

lista[i], lista[mayor] = lista[mayor], lista[i]

Por ello no necesita crear listas completas como las utilizadas en las implementaciones didácticas de Merge Sort o Quick Sort.

Síntesis

Heap Sort utiliza una estructura Heap para mantener el elemento de mayor prioridad en una posición conocida.

En un Max Heap, el valor mayor se encuentra en la raíz. El algoritmo lo intercambia con la última posición disponible, reduce el tamaño del heap y utiliza heapify() para restaurar su estructura.

Este proceso permite mantener una complejidad de O(n log n) incluso en el peor caso.
