Merge Sort: estrategia y funcionamiento

Comprender cómo Merge Sort utiliza la estrategia divide y vencerás, la recursión y la combinación de listas para alcanzar una complejidad O(n log n).

Introducción

Merge Sort es un algoritmo de ordenamiento eficiente basado en la estrategia divide y vencerás.

Su funcionamiento consiste en dividir una colección en partes cada vez más pequeñas, ordenar esas partes y posteriormente combinarlas hasta obtener una colección completamente ordenada.

1. Estrategia divide y vencerás

La estrategia divide y vencerás permite resolver un problema grande mediante la creación de problemas más pequeños.

1. Dividir

Separar la lista en partes más pequeñas.

2. Resolver

Procesar recursivamente cada una de las partes.

3. Combinar

Unir las partes nuevamente de manera ordenada.

Dividir → Resolver → Combinar

2. División de la lista

Consideremos la siguiente colección:

[8, 3, 6, 2, 7, 1, 5, 4]

Merge Sort divide la colección aproximadamente por la mitad:

[8, 3, 6, 2, 7, 1, 5, 4]

↓

[8, 3, 6, 2]      [7, 1, 5, 4]

↓

[8, 3] [6, 2]      [7, 1] [5, 4]

↓

[8] [3] [6] [2] [7] [1] [5] [4]

3. Caso base

Cuando una lista contiene uno o ningún elemento, ya puede considerarse ordenada.

[8] [3] [6] [2]
Caso base: si el tamaño de la lista es menor o igual que 1, ya no es necesario dividirla.

4. Proceso de combinación

Después de completar la división comienza el proceso inverso: combinar las listas de manera ordenada.

[8] + [3]
↓
[3, 8]
[6] + [2]
↓
[2, 6]

5. Combinación paso a paso

Supongamos que tenemos dos listas previamente ordenadas:

izquierda = [3, 8]
derecha = [2, 6]
Comparación 1: 3 vs 2 → se selecciona 2.
Resultado: [2]
Comparación 2: 3 vs 6 → se selecciona 3.
Resultado: [2, 3]
Comparación 3: 8 vs 6 → se selecciona 6.
Resultado: [2, 3, 6]
El elemento restante es 8.
Resultado final: [2, 3, 6, 8]

6. Recursión en Merge Sort

Merge Sort utiliza recursión para dividir cada parte de la lista hasta alcanzar el caso base.

merge_sort([8, 3, 6, 2])

↓

merge_sort([8, 3])     merge_sort([6, 2])

↓

merge_sort([8]) merge_sort([3]) merge_sort([6]) merge_sort([2])
Cuando la lista contiene solamente un elemento, la llamada recursiva termina y comienza el proceso de combinación.

7. Función de combinación en Python

Antes de implementar Merge Sort completo, podemos construir una función encargada únicamente de combinar dos listas que ya están ordenadas.

def combinar(izquierda, derecha):
    resultado = []

    i = 0
    j = 0

    while i < len(izquierda) and j < len(derecha):

        if izquierda[i] < derecha[j]:
            resultado.append(izquierda[i])
            i += 1
        else:
            resultado.append(derecha[j])
            j += 1

    resultado.extend(izquierda[i:])
    resultado.extend(derecha[j:])

    return resultado
Prueba 
lista1 = [3, 8]
lista2 = [2, 6]

resultado = combinar(lista1, lista2)

print(resultado)

Resultado: [2, 3, 6, 8]

9. Implementación básica de Merge Sort en Python

def combinar(izquierda, derecha):
    resultado = []

    i = 0
    j = 0

    while i < len(izquierda) and j < len(derecha):

        if izquierda[i] < derecha[j]:
            resultado.append(izquierda[i])
            i += 1
        else:
            resultado.append(derecha[j])
            j += 1

    resultado.extend(izquierda[i:])
    resultado.extend(derecha[j:])

    return resultado


def merge_sort(lista):

    if len(lista) <= 1:
        return lista

    mitad = len(lista) // 2

    izquierda = lista[:mitad]
    derecha = lista[mitad:]

    izquierda = merge_sort(izquierda)
    derecha = merge_sort(derecha)

    return combinar(izquierda, derecha)


numeros = [8, 3, 6, 2, 7, 1, 5, 4]

ordenados = merge_sort(numeros)

print(ordenados)
Resultado
[1, 2, 3, 4, 5, 6, 7, 8]

10. Complejidad de Merge Sort

Número de niveles

La lista se divide aproximadamente por la mitad en cada llamada.

8 → 4 → 2 → 1

Esto produce aproximadamente log₂(n) niveles.

Trabajo por nivel

Durante el proceso de combinación se procesan aproximadamente todos los elementos.

n × log n

O(n log n)

11. Uso de memoria auxiliar

Merge Sort normalmente necesita crear listas adicionales durante la división y combinación.

izquierda = lista[:mitad]
derecha = lista[mitad:]

resultado = []
Merge Sort mantiene un buen rendimiento temporal, pero requiere memoria auxiliar.

12. Características de Merge Sort

Característica Merge Sort
Estrategia Divide y vencerás
División Aproximadamente por la mitad
Recursión Sí
Complejidad promedio O(n log n)
Peor caso O(n log n)
Memoria auxiliar Sí
Proceso principal Dividir y combinar

Síntesis

Merge Sort divide una colección repetidamente hasta obtener problemas suficientemente pequeños.

Posteriormente combina las partes manteniendo los elementos en orden. Esta organización del trabajo permite alcanzar una complejidad de O(n log n).

La comprensión de la división, el caso base, la recursión y la combinación permite entender el funcionamiento general del algoritmo antes de analizar implementaciones más avanzadas.
