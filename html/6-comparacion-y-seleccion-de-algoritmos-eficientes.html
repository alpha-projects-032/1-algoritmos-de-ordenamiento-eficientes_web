Introducción

Merge Sort, Quick Sort y Heap Sort pueden utilizarse para resolver problemas de ordenamiento de forma eficiente, pero cada uno emplea una estrategia diferente.

La selección del algoritmo debe considerar el rendimiento esperado, la memoria disponible, la estabilidad y las características de los datos.

1. Tres estrategias diferentes

Merge Sort

Divide la colección, ordena las partes y posteriormente las combina.

Dividir → Ordenar → Combinar

Quick Sort

Selecciona un pivote y distribuye los elementos alrededor de él.

Pivote → Particionar → Ordenar

Heap Sort

Construye un Heap y extrae progresivamente el elemento de mayor prioridad.

Heap → Extraer → Restaurar

2. Comparación de complejidad temporal

4. Estabilidad

Un algoritmo de ordenamiento es estable cuando conserva el orden relativo original de elementos que poseen la misma clave.

Ana      85

Ana      85

Carlos   90

Heap Sort No

7. Criterios de selección

Merge Sort
  • Se necesita estabilidad.
  • Se requiere O(n log n) predecible.
  • La memoria adicional es aceptable.
Quick Sort
  • Se busca buen rendimiento promedio.
  • Puede utilizarse una buena estrategia de pivote.
  • El peor caso puede mitigarse.
Heap Sort
  • La memoria auxiliar debe limitarse.
  • Se requiere O(n log n) en el peor caso.
  • No se necesita estabilidad.

10. Medición básica de tiempo

import time

numeros = [8, 3, 6, 2, 7, 1, 5, 4]

inicio = time.perf_counter()

resultado = merge_sort(numeros)

fin = time.perf_counter()

print("Tiempo:", fin - inicio)
Una única medición con pocos elementos no permite concluir que un algoritmo sea siempre más rápido que otro.

Síntesis

Merge Sort, Quick Sort y Heap Sort pueden alcanzar un rendimiento eficiente, pero utilizan estrategias diferentes.

Merge Sort ofrece un comportamiento O(n log n) predecible y estabilidad habitual. Quick Sort destaca por su buen comportamiento promedio, aunque puede alcanzar O(n²). Heap Sort mantiene O(n log n) incluso en el peor caso y requiere poca memoria auxiliar.

La selección debe considerar conjuntamente la complejidad temporal, memoria, estabilidad, distribución de los datos y necesidades particulares del problema.
