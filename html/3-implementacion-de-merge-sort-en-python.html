6. Agregar elementos restantes

Cuando una lista termina antes que la otra, los elementos pendientes pueden agregarse directamente.

resultado.extend(izquierda[i:])
resultado.extend(derecha[j:])
Como las listas de entrada ya están ordenadas, los valores restantes pueden incorporarse sin realizar nuevas comparaciones entre ambas listas.

7. Función combinar() completa

def combinar(izquierda, derecha):
    resultado = []

    i = 0
    j = 0

    while i < len(izquierda) and j < len(derecha):

        if izquierda[i] < derecha[j]:
            resultado.append(izquierda[i])
            i += 1
        else:
            resultado.append(derecha[j])
            j += 1

    resultado.extend(izquierda[i:])
    resultado.extend(derecha[j:])

    return resultado

14. Implementación completa

def combinar(izquierda, derecha):
    resultado = []

    i = 0
    j = 0

    while i < len(izquierda) and j < len(derecha):

        if izquierda[i] < derecha[j]:
            resultado.append(izquierda[i])
            i += 1
        else:
            resultado.append(derecha[j])
            j += 1

    resultado.extend(izquierda[i:])
    resultado.extend(derecha[j:])

    return resultado


def merge_sort(lista):

    if len(lista) <= 1:
        return lista

    mitad = len(lista) // 2

    izquierda = lista[:mitad]
    derecha = lista[mitad:]

    izquierda = merge_sort(izquierda)
    derecha = merge_sort(derecha)

    return combinar(izquierda, derecha)


numeros = [8, 3, 6, 2, 7, 1, 5, 4]

Síntesis

La implementación de Merge Sort puede dividirse en dos responsabilidades: merge_sort() controla la división recursiva y combinar() reconstruye las listas de forma ordenada.

Comprender el caso base, los índices, las comparaciones, la recursión y la construcción progresiva del resultado permite interpretar el algoritmo más allá de simplemente ejecutar su código.
