Ordenamientos eficientes

Fundamentos de los ordenamientos eficientes

Comprender por qué algoritmos como Merge Sort, Quick Sort y Heap Sort permiten ordenar grandes cantidades de datos de manera más eficiente.

Introducción

Los algoritmos de ordenamiento permiten reorganizar un conjunto de datos siguiendo un criterio determinado, por ejemplo, de menor a mayor, de mayor a menor o según alguna característica de los elementos.

Cuando la cantidad de datos aumenta, la eficiencia del algoritmo se vuelve un factor importante. No solamente interesa obtener el resultado correcto, sino también hacerlo utilizando una cantidad razonable de operaciones.

1. ¿Por qué necesitamos algoritmos eficientes?

Algunos algoritmos sencillos de ordenamiento pueden realizar una gran cantidad de comparaciones e intercambios.

Bubble Sort

Comparaciones repetidas entre elementos vecinos.

Selection Sort

Busca repetidamente el elemento que debe ocupar cada posición.

Insertion Sort

Inserta cada elemento en su posición correspondiente.

Muchos algoritmos sencillos presentan un comportamiento aproximado de O(n²), lo cual puede resultar costoso cuando el número de elementos aumenta.

2. Crecimiento O(n²)

La expresión O(n²) indica que el trabajo realizado por el algoritmo puede crecer aproximadamente de forma cuadrática respecto al número de elementos.

5. Estrategias de los algoritmos eficientes

Merge Sort

Divide la colección en partes más pequeñas y posteriormente las combina de forma ordenada.

Dividir → Ordenar → Combinar

Quick Sort

Selecciona un pivote y reorganiza los elementos según sean menores o mayores que ese valor.

Particionar → Ordenar

Heap Sort

Utiliza una estructura Heap para localizar y extraer progresivamente los elementos.

Heap → Extraer → Reorganizar

7. Recursión

Merge Sort y muchas implementaciones de Quick Sort utilizan recursión.

La recursión ocurre cuando una función se llama a sí misma utilizando un problema cada vez más pequeño.

ordenar(8 elementos)
↓
ordenar(4 elementos)
↓
ordenar(2 elementos)
↓
ordenar(1 elemento)
Caso base

Es la condición que permite detener las llamadas recursivas cuando el problema ha alcanzado su forma más pequeña.

8. Ejemplo de recursión en Python

El siguiente ejemplo permite observar una llamada recursiva sencilla.

def cuenta_regresiva(numero):
    if numero == 0:
        print("Fin")
        return

    print(numero)
    cuenta_regresiva(numero - 1)


cuenta_regresiva(5)

9. División recursiva de una lista

El siguiente ejemplo todavía no ordena los elementos. Su objetivo es mostrar cómo una lista puede dividirse recursivamente.

def dividir(lista):
    print(lista)

    if len(lista) <= 1:
        return

    mitad = len(lista) // 2

    izquierda = lista[:mitad]
    derecha = lista[mitad:]

    dividir(izquierda)
    dividir(derecha)


numeros = [8, 3, 6, 2, 7, 1, 5, 4]

dividir(numeros)
Observa
  • La lista original se divide en dos partes.
  • Cada parte vuelve a dividirse.
  • El proceso continúa hasta obtener listas de un elemento.
  • len(lista) <= 1 funciona como caso base.

Práctica en Python

Sustituye la lista utilizada anteriormente por:

numeros = [12, 5, 9, 1, 15, 7]

dividir(numeros)

Analiza el resultado:

  1. ¿Cuántas divisiones realiza el algoritmo?
  2. ¿Qué ocurre cuando una lista contiene un único elemento?
  3. ¿Qué ocurre cuando la cantidad de elementos es impar?
  4. ¿Qué función cumple len(lista) <= 1?
  5. Crea una nueva lista con 10 elementos y observa sus divisiones.

Síntesis

Los algoritmos de ordenamiento eficientes buscan reducir la cantidad de trabajo necesario cuando aumenta el volumen de datos.

La complejidad O(n log n) aparece frecuentemente cuando el algoritmo procesa los elementos mientras divide, reorganiza o estructura el problema en varios niveles.

Merge Sort, Quick Sort y Heap Sort utilizan estrategias diferentes. Comprender estas estrategias permitirá analizar posteriormente cuál algoritmo resulta más apropiado para cada problema.
